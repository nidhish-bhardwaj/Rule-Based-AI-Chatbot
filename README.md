# Rule-Based AI Chatbot

## Project Overview

This project is a simple Rule-Based AI Chatbot developed using Python.

The chatbot uses predefined rules and `if-elif-else` conditions to analyze user input and provide appropriate responses.

This project is part of **Project 1: Rule-Based AI Chatbot** from the DecodeLabs Artificial Intelligence Internship.

---

## Objective

The main objective of this project is to understand the basics of:

- Control Flow
- Decision-Making Logic
- `if-elif-else` conditions
- `while` loops
- User input handling
- Basic Artificial Intelligence concepts

---

## Features

The chatbot can:

-  Respond to greetings
-  Tell the user who it is
-  Respond to "How are you?"
-  Explain Artificial Intelligence
-  Explain Machine Learning
-  Explain how the chatbot works
-  Respond to help requests
-  Respond to thank-you messages
-  Handle exit commands
-  Provide a default response for unknown questions

---

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Concepts:** `if-elif-else`, `while` loop
- **Input Processing:** String methods such as `.lower()` and `.strip()`

---

## How the Chatbot Works

The chatbot works using predefined rules.

1. The chatbot starts and displays a welcome message.
2. It continuously takes input from the user.
3. The input is converted to lowercase and extra spaces are removed.
4. The chatbot checks the input using `if-elif-else` conditions.
5. If a matching rule is found, the chatbot gives the predefined response.
6. If the user enters `bye`, `exit`, or `quit`, the chatbot ends the conversation.
7. If no rule matches the input, the chatbot provides a default response.
